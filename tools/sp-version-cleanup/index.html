Quick Reference: Automatic Trim Behavior

When EnableAutoExpirationVersionTrim is set to $true, SharePoint applies time-based thinning with a max of 500 versions:

0-30d: ALL
30-60d: Hourly
60-180d: Daily
180d+: Weekly
ParameterTypeDescription
EnableAutoExpirationVersionTrimBooleanEnable/disable intelligent auto trimming
MajorVersionLimitIntegerMax major versions to retain (used when auto trim is off)
ExpireVersionsAfterDaysIntegerDelete versions older than N days (0 = never expire)
