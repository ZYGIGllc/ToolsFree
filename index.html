SP Version Cleanup

SharePoint Online version-management script generator

Available now

File versions quietly eat a tenant's storage quota. This tool builds the PowerShell for you: fill in a site URL, pick a job, and copy out a ready-to-run script for intelligent versioning, storage cleanup, auditing, or bulk operations across every site in the tenant. It only needs the SharePoint Online Management Shell — no extra modules — and the scripts are generated in your browser, so no URL, tenant name, or setting is ever sent anywhere.

  • Enable automatic version trim on a site
  • Set manual version count and age limits
  • Check current version settings and storage
  • Run a trim job with progress monitoring
  • Submit trim jobs tenant-wide
  • Enable auto trim across all sites
  • Export a version-settings audit to CSV
  • Enable auto trim on all OneDrive sites
  • Generate version reports for every site
